# 对比度计算与实测

配色是否"看得清"不该靠目测。这里给出可复现的算法、全部实测值和修正策略。

---

## 公式

```
对比度 = (L亮 + 0.05) / (L暗 + 0.05)
```

相对亮度：

```
对每个通道 c（0-1）：
  c' = c / 12.92                    若 c ≤ 0.03928
  c' = ((c + 0.055) / 1.055) ^ 2.4   否则

L = 0.2126R' + 0.7152G' + 0.0722B'
```

那个 2.4 次幂是 sRGB 反伽马，不能省略。用 RGB 平均值直接算会得出错误结果，浅色区误差尤其大。

## 带 alpha 的色值必须先合成

设计令牌里大量使用 `#1c1c1cad` 这类八位色值。计算前要先与背景合成：

```
合成通道 = 前景通道 × alpha + 背景通道 × (1 - alpha)
```

例如 `#1c1c1cad`（alpha 68%）放在白底上，实际是 `#5b5b5b` 左右，对比度 5.83。若直接取 `#1c1c1c` 计算，会得出 17.04 这个完全错误的结论。

这也是为什么读到八位色值时不能跳过合成步骤。

## 判定阈值

| 用途 | AA | AAA | 建议 |
|---|---|---|---|
| 正文 | 4.5 | 7 | ≥12 |
| 次要文字 | 4.5 | 7 | 5-7 |
| 辅助标签 | 4.5 | 7 | 4-5 |
| 占位符、禁用 | 无 | 无 | 允许 <3 |
| 语义文字色 | 4.5 | 7 | 与填充色分开准备 |
| 图表色块 | 3.0 | 4.5 | 图形非文本 |
| 纯装饰、分隔线 | 无 | 无 | 3.0 即可 |

正文建议 12 以上，因为屏幕反光、亮度调节、环境光都会削弱实际对比。留余量比刚好达标稳妥。

## 实测：文字四级（白底合成后）

| 令牌 | 值 | alpha | 对比度 | 判定 |
|---|---|---|---|---|
| text-primary | `#1c1c1c` | 100% | 17.04 | AAA |
| text-secondary | `#1c1c1cad` | 68% | 5.83 | AA |
| text-tertiary | `#1c1c1c8f` | 56% | 3.95 | 大字号 |
| text-quaternary | `#1c1c1c66` | 40% | 2.49 | 装饰 |

阶梯跨度均匀。后两档低于 AA 是刻意的：占位符和禁用态不需要清晰可读，只需要"存在但不可用"的暗示。

| 家族 | 填充 | 对比度 | 文字 | 对比度 |
|---|---|---|---|---|
| accent | `#1680f3` | 3.88 | `#0b6dd3` | 5.07 |

填充全部低于 4.5，文字全部高于 4.5。这个整齐分界说明是按用途分配，不是随手取色。

## 修正策略

对比度不足时按此顺序尝试，越靠前对整体观感影响越小：

1. **调明度**。同色相下压暗前景或提亮背景，色相不变，风格不受影响。
2. **调背景**。前景由品牌规定不能改时，把容器底色往反方向推一档。
3. **另配文字色**。填充色保留，为文字单独准备一个更深的版本。这是最推荐的做法，代价最小。
4. **加大字号或字重**。降低阈值要求（大字 3.0），属于妥协不是解决。
5. **换色相**。最后手段，会破坏色板一致性。

避免：加文字阴影、加描边、加半透明底衬。这些都让边缘变糊，实际可读性反而下降。

## 快速估算

手边没有工具时，用 HSL 的明度差粗判：

- 明度差 > 60：通常 > 7
- 明度差 40-60：约 4.5-7
- 明度差 < 30：很可能不足 4.5

仅适用于同色相两色。跨色相会失效，因为绿色在亮度公式中权重最高（0.7152），同样明度的红绿实际对比度差别很大。

## 常见错误配对

| 问题 | 对比度 | 修正 |
|---|---|---|
| 深色底 + 纯白 `#ffffff` | 17.9 | 降到 `#f0f0f0`，减少刺眼感 |
| 填充绿 `#10ab61` 写小字 | 2.99 | 换 `#00854a`（4.71） |
| 灰色 `#999` 放白底 | 2.85 | 改 `#767676`（4.54） |
| 浅蓝 `#60a5fa` 放白底 | 2.54 | 改 `#2563eb`（5.17） |
| 深色卡片内用 `#444` 做次要文字 | 1.6 | 深色主题的次要文字要提亮，方向相反 |
| 直接用 `#1c1c1c` 算 `#1c1c1cad` 的对比度 | 17.04（错误） | 先与背景合成，实际 5.83 |

最后一条最隐蔽：八位色值不合成直接算，会得出完全失真结论。
