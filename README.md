# dashboard-palette-design

为数据看板、分析报告、监控界面设计配色的方法论与可直接取用的令牌体系，以技能（skill）形态交付。

不含依赖，不需要安装。核心是三层令牌结构加六条规则，全部色值与对比度来自实际样式表的逆向提取。

## 内容

| 文件 | 说明 |
|---|---|
| `SKILL.md` | 主文件。六条规则、可复制色板、工作流程、反模式 |
| `reference/palettes.md` | 完整令牌表、语义色派生矩阵、图表色板、组件用法 |
| `reference/contrast.md` | 计算方法、全部实测值、修正策略 |

## 六条规则

1. **基础色不超过三个** — 墨、纸、品牌，其余派生
2. **文字层级用 alpha** — 同一墨色四档透明度，自动适配任何底色
3. **填充色和文字色分开** — 填充可以低对比，文字必须 ≥4.5
4. **系列色按色相间隔排序** — 前几位避开相近色相，蓝与紫不要相邻
5. **色阶中点是背景色** — 零值才会自然融入
6. **透明度预置替代重复定义** — 系列色加 alpha 后缀，不为每个色再造浅版

## 一个典型例子

同一套色板里，成功绿有两个值：

```css
--success:      #10ab61;   /* 填充，白底对比度 2.99 */
--text-success: #00854a;   /* 文字，白底对比度 4.71 */
```

用第一个绿色写小字，标签会糊在背景里。这个分离是专业配色与随手取色的分水岭。

## 何时有用

- 让 AI 生成 HTML 看板或报告，需要稳定好看的配色
- 现有界面说不上哪里怪，需要定位
- 图表多条线分不清，需要重排系列色
- 深色与浅色主题要共用一套设计语言
- 文字可读性存疑，需要可计算的判断

## 何时没用

- 需要完整设计系统（组件库、动效、排版比例），这里只覆盖颜色
- 追求强视觉冲击的营销页，这套方法偏向克制与可读
- 已有成熟品牌规范且不能改动

## 来源

色值与令牌结构提取自一个商业桌面客户端（Electron，0.78.4）的实际样式表，共 312 组定义，分布在三套并行体系：浅色界面（234 个）、深色编辑器（67 个）、双主题图表（21 个）。

对比度按 WCAG 2.1 逐项计算，带 alpha 的值先与背景合成。系列色重排的依据是色相环上的实际角度差，不是主观判断。
